# Control Flow Practice – NOVI Backend Java Assignment

## About the Project

This repository contains my solutions for the **Control Flow** assignment from the Backend Java module at [Novi University](https://www.novi.nl).

The goal of this assignment is to practice using different control flow constructs in Java — including **if-else statements**, **switch blocks**, and **while**/**for loops**. In the bonus assignment, multiple control flow structures are combined to solve more complex logic.

## How to Run

1. Open the project in your IDE (IntelliJ IDEA)
2. Navigate to the `Main` class
3. Locate the `main` method and click the green play button to **Run 'Main'** or use the terminal:
    ```bash
   mvn clean compile exec:java
   ```
